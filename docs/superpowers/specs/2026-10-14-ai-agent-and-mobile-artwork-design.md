# AI agent and mobile artwork refresh

## Purpose

Make the AI inbox agent offer feel warm and tangible, and make the native Venmail apps a prominent, credible part of the landing page.

## AI inbox agents

- Replace the current product-led teaser artwork with a hybrid composition.
- Retain the deep-charcoal inbox panel, rounded product cards, warm off-white field, coral, mint, and soft lilac palette from the selected product-led direction.
- Replace the abstract coral star-like assistant motif with the friendly, coral assistant character from the illustration-led direction.
- Do not use a humanoid robot, glossy 3D treatment, logos, accidental readable text, watermarks, or third-party messaging marks.
- Preserve the current 1586 x 992 rendered-asset contract and `next/image` sizing behavior.
- Use the channel copy: `Connect a dedicated Venmail inbox to an AI agent. Talk to your AI mail agent over Telegram or WhatsApp.` The adjacent channel-status rows remain the sole availability qualification.

## AI inbox agent destination

- Keep `/venmail-agent` for the separate Chrome contact-intelligence extension; it must not be presented as the AI inbox agent product.
- Create `/ai-inbox-agents` as the public product page for AI inbox agents.
- Link the landing-page AI inbox section to `/ai-inbox-agents`; retain registration as the secondary action. The public product page owns the direct management link to `https://m.venmail.io/admin/agents`.
- Add an `AI inbox agents` destination to the product navigation and company footer alongside, rather than in place of, the existing extension destination.
- Explain the actual offer: a dedicated inbox per agent, natural-language conversation over Telegram or WhatsApp, and up to 20 saved routines per agent. Keep the existing visible Telegram and WhatsApp status qualifications.

## Native mobile apps

- Render a dedicated native-app section immediately after AI inbox agents and before the broader product suite section.
- Use two premium, overlapping portrait phone devices: a primary device with a real Venmail inbox capture from an official store listing and a secondary device with a complementary crop of that same authentic application UI.
- The artwork must be editorial rather than photorealistic: warm off-white background, charcoal device frames, coral accent, pale mint, and soft lilac supporting shapes. It must visually belong with the landing page rather than resemble generic App Store marketing.
- State iOS and Android availability prominently.
- Keep the verified current outbound destinations:
  - App Store: `https://apps.apple.com/us/app/venmail/id6755040289`
  - Google Play: `https://play.google.com/store/apps/details?id=io.venmail.app`
- Use accessible labels that name the destination and preserve secure external-link behavior.
- Reuse the existing mobile-app section only where it helps; replace its generic visual treatment and render it from the homepage.

## Validation

- Confirm both store links, external-link attributes, and accessible labels in source tests.
- Verify the artwork dimensions and image rendering contract.
- Run the content, tooling, and production-build checks.
- Visually inspect desktop and mobile layouts before release.
